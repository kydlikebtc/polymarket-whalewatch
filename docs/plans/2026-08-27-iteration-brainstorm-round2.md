# 产品迭代脑暴 · 第二轮 —— 不受历史清单约束的 20 个方向

> 日期：2026-08-27
> 性质：脑暴快照（与 [战略总纲](2026-07-10-polymarket-monitor-strategic-roadmap.md) 互补，不替代）
> 前提共识：30 天数据闸门只锁「我们的信号有 edge」类主张；「让市场自己的事实更好看」
> 与「让同一份数据出现在更多地方」两条路径不经过闸门。
> 用户裁决（同日）：先做「最高杠杆组」（#11 MCP + #13 嵌入卡 + #19 数据集）与
> 「内容引擎组」（#5 异常日榜 + #6 散户vs鲸鱼 + #8 校准研究）；其余留档待择。

体量标记：S=几天 / M=一两周 / L=一个月级。「闸门无关」= 不主张自家信号 edge，
不受 30 天不间断数据闸门约束。

## A. 还没在看的数据面（现在只看成交，市场还有三层没拆）

1. **挂撤单事件流**（L，闸门无关）——CLOB WebSocket 的下一层：买墙立起/撤走、
   挂 90 秒即撤的 spoofing 嫌疑、结算前买墙变薄。成交是结果，挂撤单是意图；
   竞品几乎无人做，天然内容素材。
2. **对手盘视角**（M）——鲸鱼的单谁接的？做市商（正常）还是散户追价（危险）？
   同一份成交流换个 join 方向，零新增抓取。
3. **跨平台价差带**（M，闸门无关）——同一事件 Polymarket vs Kalshi vs Pinnacle
   赔率并排。总纲否的是套利**执行**，只读价差展示是另一回事。
4. **催化剂时间轴**（M）——信号图叠新闻时间戳，把「鲸鱼在新闻前 4 小时进场」
   从叙事变成可量化字段。

## B. 同一份库换个问法就是新产品（S–M，全部闸门无关）

5. **「十大异常市场」日榜**（✅ 本批实施）——不跟钱包，给市场排怪异度（量能异动、
   单边流、鲸鱼占比、新钱包涌入、日内价移）。每天自动出榜 = 内容引擎 + 研究漏斗。
6. **散户 vs 鲸鱼分歧指数**（✅ 本批实施）——按单笔金额分桶算方向背离。
   「散户在买、鲸鱼在出」是预测市场最经典的逆向内容，少数人真能算出来。
7. **鲸鱼行为改变检测**（M）——对已知钱包做行为异常：规模 ×5、专精赛道外首单、
   沉默 60 天复活。「他变了」比「他下了大单」高一个量级。
8. **市场校准研究**（✅ 本批实施）——用已积累结算数据算 Polymarket 自身按赛道的
   校准曲线。不是「我们的信号」，是市场基线研究——学术级引用素材、GEO 顶级弹药。
9. **事件级概率加总检测**（M）——相关子市场概率和 ≠ 100% 的错价扫描。README
   「事件级累计」管仓位，这条管定价矛盾，姊妹篇。

## C. 新形态与分发（产品的皮不止是网站）

10. **浏览器插件：情报叠在 polymarket.com 上**（L，最大战略赌注）——市场页原位
    浮出聪明钱持仓、钱包页浮出战绩徽章。把数据送到决策瞬间；只读定位不变；
    将来 Builder 归因的天然载体。唯一同时满足「决策瞬间分发 + 只读信任 +
    通往执行层的钱」的形态，值得单独立项评审。
11. **MCP Server**（✅ 本批实施，S）——把只读 API 包成 MCP server，让 Claude/任何
    agent 直接查鲸鱼数据。成本近零，进 MCP 目录 = AI 原生获客渠道，预测市场第一个。
12. **Telegram Mini App**（M）——信号 feed 包成 TG 小程序，骑在既有分发上。
13. **可嵌入卡片**（✅ 本批实施，S）——战绩卡/状态徽章做成 iframe embed，
    每次嵌入都是带署名的分发。
14. **自助规则 + 个人 webhook**（M）——访客自己拼过滤器领个人推送；把总纲 P1.3
    多规则告警倒过来做成增长循环（规则可分享，分享即拉新）。
15. **AI 周报 + 「问盘面」**（M，守总纲红线：只总结可追溯事实）——周报 LLM 起草
    人审后发；站上只读问答框，每个答案带数据链接。

## D. 钱的新路径（在「订阅天花板极低」结论下重想）

16. **Builder 返佣的零执行准备**（S）——「去看看」深链换成带 builder 归因；
    用户自己下单我们收归因费，托管资金为零。归因基建先行，返佣开关等信号质量达标。
17. **B2B pro 终端**（M–L）——做市商/基金要的是流量情报不是跟单信号。高限额
    API + 流向分析 + CSV 导出，5 个专业买家胜过 500 个散户订阅。
18. **白标/多市场引擎**（L，远期）——整套「盯 CLOB 大钱包」引擎是通用的，
    Kalshi 开放即平移；OSS 核心 + 付费部署，Rust 重写的战略归宿。
19. **公开数据集**（✅ 本批实施，S）——定期发布哈希链背书的已结算信号导出。
    研究者引用你 = 别人替你建护城河。

## E. 引擎跃迁

20. **WebSocket 实时化**（L）——fills 检测 4 秒轮询 → 亚秒推送。对赛前/滚球
    不是优化是换维度；mm-whalewatch Rust 线的天然靶子。

## 结构性判断（为什么先做这两组）

- **最高杠杆组**（11+13+19）：全是把现成资产换个出口，各开一条新分发，
  合计一周内可全部上线。
- **内容引擎组**（5+6+8）：三者共享同一个每日聚合底座，产出可直接喂 X 播报，
  把「每天有话说」变成自动的。
- 明确不在本批：X 播报接入新内容类型（触 xQuota/模板/manage 三处，独立批次）；
  浏览器插件（#10）单独立项评审；其余条目留档待择。

# 策略中心 · 历史下注深度分析面板 — 设计

日期:2026-08-13。需求:给策略中心所有策略的全部历史下注做一个深度分析面板,
分析维度自主脑暴确认(用户授权)。

## 1. 目标与读者

读者是「判断哪档策略有真实优势、值不值得实盘跟」的人。现有五个 tab(总览/
成本分解/账户推演/操作历史/仓位明细)回答了「赚了多少、成本多少、备多少钱、
做了什么、每仓明细」,但没有回答四个分析性问题:

1. **钱从哪赢来的?**(赔率结构/赛道/时长)
2. **赢是运气还是本事?**(校准:实际胜率 vs 入场价隐含胜率)
3. **优势在衰减吗?**(时间走势)
4. **风险长什么样?**(连败/集中度/盈亏分布)

深度分析面板补这一层。

## 2. 口径红线

- **已结算口径**:与整页一致只看 settled(落袋),不做浮盈;持有中仓数仅在
  头部作说明,不进任何指标。
- **纸面口径**:不混入追价/协议费等成本(成本分解 tab 已覆盖),头部说明。
- **push 纪律**:realized_pnl===0 视为平局,不进胜率分母(与
  computeStrategyMetrics 一致)。
- **小样本诚实**:整体 settled<10(LOW_SAMPLE_THRESHOLD 同源)出横幅;分桶
  n<5 弱化显示;胜率带 Wilson 区间;期望给 t 值而非只给均值。

## 3. 六个维度

### ① 下注质量体检(顶部指标行)

期望 $/仓、期望 t 值(mean/(sd/√n),n<2 或 sd=0 为 —)、利润因子
(总盈/总亏,无亏损仓为 —)、盈亏比(均盈利仓 $ / 均亏损仓 $)、最佳/最差
单仓、胜率+Wilson 区间。

### ② 赔率带校准(核心)

入场价 5 档分桶:<20¢ / 20–40¢ / 40–60¢ / 60–80¢ / ≥80¢。每桶:仓数、
实际胜率、隐含胜率(该桶均入场价 —— 入场价本身就是市场定价的概率)、
edge = 实际 − 隐含、落袋合计。呈现:表格 + 每桶「实际 vs 隐含」双条
(CSS 宽度条,不引图表依赖)。这是预测市场特有的「运气 vs 本事」检验:
edge 持续为正才是可复制的优势。

### ③ 时间走势

- 周度盈亏柱状图(UTC 周一起算分桶,正绿负红,SVG 迷你柱图;空周补零保持
  时间轴等距,防御上限 60 桶)。
- 前半 vs 后半对比(按结算时间排序对半分):各自 n/胜率/落袋 —— n≥6 才显示,
  小样本下比滚动曲线更诚实的衰减检测。

### ④ 连胜连败 · 盈利集中度

最长连胜、最长连败、当前 streak(按 exit_ts 升序;push 跳过不重置)、
Top3 盈利仓占总盈利比、去掉 Top3 盈利后的净盈亏(稳健性:是不是几笔大的
撑起来的)、对称给 Top3 亏损占总亏损比。

### ⑤ 持有时长分布

5 档:<6h / 6–24h / 1–3d / 3–7d / >7d。每桶 n、胜率、落袋。回答「钱在
快市场(in-play 体育)还是慢市场赢的」。

### ⑥ 赛道细分

category × n、胜率、均入场价、落袋。比现有 byCategory(只有 realized+count)
多胜率与均入场;未分类归「未分类」。

**否决的候选**(YAGNI):入场时段(时/星期)——样本撑不起 24×7 网格;
滚动胜率曲线——小样本下前/后半更诚实;Kelly 仓位建议——过度工程;
持仓敞口分析——非「历史下注」语义;成本维度——成本分解 tab 已有。

## 4. 架构

```
lib/followAnalysis.ts        client-safe 纯函数(仿 followCardView 先例)
  analyzeBets(rows) → DeepAnalysis   全部维度一次算完;TDD 全覆盖
lib/follow.ts buildFollowView       每行仓位附 category(server 已算好
                                    categoryByCid,只是此前没随行下发)
app/follow/DeepAnalysis.tsx         面板组件(独立文件,遵守文件大小规范)
app/follow/page.tsx                 两个入口(见 §5)
```

数据流:/api/follow 原有响应 + 每行 `category` 字段 → 客户端在面板打开时
惰性调用 analyzeBets(与详情弹窗 !open 短路同一套惰性纪律)。

## 5. 入口(方案对比后选 C)

- A. 仅详情弹窗加 tab:最小,但无跨策略聚合视图。
- B. 仅页面级全局面板 + 策略选择器:聚合好,但与详情弹窗 IA 重复。
- **C. 共享面板组件 + 双入口(选定)**:
  1. StrategyDetailDialog 新增「深度分析」tab,紧跟「总览」(总览是结论,
     深度分析是深挖,阅读顺序自然;其余 tab 相对顺序不动)。
  2. 页面「仓位明细」区头部加「深度分析」按钮,弹 Modal 分析当前筛选
     (全部策略聚合或某一档)——复用现有 stratFilter,不新造选择器。
     聚合视图标注「多档策略会跟进同一信号,聚合样本含重复下注」。

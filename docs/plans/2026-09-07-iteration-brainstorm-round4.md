## A. 连续性保险 —— 30 天 streak 是护城河 #1，最便宜的保险先买

1. **上游调用计量表**（S，闸门无关）—— `fetchWithRetry` 按 `label`（已有参数）
   计数：次数 / 408 / 429 / 耗时，按分钟桶落一张 `upstream_calls` 小表（或并入
   `cycle_metrics`），/manage 健康度加「上游调用/分钟 · 429 占比 · 逐 label 前五」。
   所有「带闸上」的方向（第三轮 #9/#12/#13、本轮 B3/E1/F1）从此有实测量尺。
   零上游、KB 级存储。**本轮第一推荐**：不是功能，是其它所有预算决策的仪表。
2. **market_daily 循环心跳**（S）—— 补 `beat(db, "market_daily")`、阈值 26h
   （日频循环）、`loopMeta` 文案「脉搏日榜与确信指数停更」、/status 一行；
   ARCHITECTURE 的「8 loops」同步改 9。半天工作量，堵一个静默失效面。
3. **异地备份**（S）—— `dbBackup` 成功后可选推到 S3 兼容对象存储（Cloudflare R2
   免费额度 10 GB，与已在前面的 Cloudflare 同栈；四个 `R2_*` env 全有才启用）。
   推送失败只记日志 + 🩺 自检里报一行，不影响引擎。库几十 MB × 7 份远在额度内。
4. **存储台账**（S）—— /manage 健康度加逐表行数 / 字节（`dbstat` 或 `page_count`）
   与 7 日增速。第三轮的「×8 落盘」从此是实测；也是 E1 能否谈的前提。
5. **访客统计**（S，近零代码）—— 已在 Cloudflare 代理之后 → 开 Cloudflare Web
   Analytics（免 cookie，代理站点后台一键注入，零代码）；或退一步在 server 端按
   路由落日计数（不存 IP）。用途：/pulse、/follow、/selftest 到底谁在看；X 粉是否
   僵尸（看 X→站点跳转）。所有产品裁决第一次有访客侧证据。
6. **循环级跨日 uptime**（S–M）—— `heartbeats` 每循环只留当日计数，/status 因此
   拒画 uptime 条；`continuity` 已用 `cycle_metrics` 给共识循环画出 60 天条。把
   heartbeats 改成「每循环每日追加一行」（cycles / max_gap），其余循环也能画条，
   一格一行原始数据背书。

## B. 「拉」式出口 —— X 触达 0.17% 之后，把分发放到不经算法闸的通道

7. **RSS / Atom**（S，闸门无关）—— /record、/pulse、/alerts 三个 feed，纯本地表、
   零上游、零 PII；RSS→TG 转发 bot、Feedly、Zapier、任何 agent 都能接。Next
   route 各 30 行；sitemap / llms.txt 同步登记。
8. **每周战报邮件**（M）—— 唯一没用过的留存渠道；周报 OG 图（`/api/og/weekly`）
   已有。代价是新增一类 PII 资产（订阅邮箱，SECURITY.md 要加一节）；发送走
   Resend 免费档（3,000 封/月）；退订链接必带。**只发周报不发信号** —— 信号进邮件
   会打乱 realtime/delayed 的通道语义。
9. **TG bot 关注清单**（M）—— bot 循环已在跑 `getUpdates`，当前只回市场卡。加
   `/watch 0x…` 与 `/watch <市场链接>` → DM 推该钱包 / 该市场的大额成交。匹配发生
   在 alert 循环**已拉取**的成交上（零新增上游，只有推送成本）；新表 `bot_watches`
   （chat_id, kind, key），每人上限 N 条，复用 claim-then-send。总纲 §12 悬了两个月
   的「频道广播 vs 可交互私聊」裁决第一次有了便宜的实验形态。与第二轮 #14 同族，
   但砍掉 web 规则编辑与 webhook。
10. **人审转发草稿队列**（S–M）—— 自回复无分发（17 条合计 13 次浏览），解法不是
    机器多发，而是让**人**从个人号发。/manage 加「今日可发草稿」：引擎按既有模板
    生成 3–5 条（含图卡），运营者一键复制 / 下载，从个人账号手发或回复大 V。零 API
    花费，绕过账号降权疑云；顺手做了记忆里「是否被判 spam」的 A/B。
11. **帖子图卡化**（S）—— 08-31 未做项：`postWithPng` 只有 weekly 在用。给
    whale / consensus / scorecard 各加一个 OG 路由（Etherscan 风三张嵌入卡已是现成
    模板）。图不算链接，$0 额外；也是 #10 的原料。

## C. 闸门后的第二幕 —— 重推 → 采纳 → 存证

12. **挑战者档一键立项**（S–M）—— 从存活变体 → admin 动作 `INSERT` 新

    `parent_code` 血缘。纪律全部不变：不改存量档、只做收紧/平移、≤3 档/次、

13. **参数与档位定义进存证链**（S）—— 每日摘要多混入
    `sha256(当日 config_history 增量 ‖ 全部档位 params_json)`，与信号摘要一起发到
    公开频道。「阈值没被悄悄挪过」从运营者承诺变成第三方可验；零上游。
14. **公开验证器**（S）—— `scripts/verify-digest.ts`（拉 `/api/dataset/record.csv`
    复算整条链）+ MCP 工具 `verify_record` + /record 一个「自己验」按钮（浏览器端
    WebCrypto 对 CSV 复算，零服务端成本）。可信度主张从「理论上可验」变成「一键验」。
15. **假设台账**（S）—— 名人堂 / 反指名单 / 渠道记分卡各自披露「未做 Bonferroni」；
    建一张 `hypotheses` 登记表（名称、首次检验日、累计检验次数、当前 z），/record
    或 /guide 出一节「本站累计检验了 N 个假设」。多重比较预算变成公开数字 ——
    这是「系统会怀疑自己」的账本化。
16. **组合净值曲线**（S，闸门无关的展示）—— /follow 只有逐档；加「全部非反向档等权
    $1k」的费后净值曲线与最大回撤（纯投影，`realized_pnl` + `fee_usd`）。周报图第二张。

## E. 一条值得用数字重议的红线（需人类裁决）

23. **有界成交环形缓存**（M）—— 现状：alert 循环每 4 秒拉 ≥$10k 成交、共识循环每
    5 分钟拉 $2k 6h 深窗口、`market_daily` 午夜**再拉一次** 24h 窗口 —— 这些字节
    都已经过内存，只是不落盘。总纲 §9 红线原文是「**默认无限**归档**全部**原始
    数据」；「$2k 档 · 7–30 天 · 超期硬删 · 默认关」既不无限也不全部。
    量级（待 A4 实测）：README 实测 24h ≥$10k 成交 1,911 笔；$2k 档按 5–10 倍估
    1–2 万笔/日 × 最小列 ~200 B ≈ 2–4 MB/日 → 30 天 ≤120 MB → ×8 备份 ≈ 1 GB。
    收益：① walk-forward **放松方向**回放（设计 §2.1 自认的可观测锥缺口，目前唯一
    诚实做法是开新档向前跑）；② 第二轮 #2 对手盘、第三轮 #2′ 盘中无鲸异动从「另立项」
    降到 S；③ `market_daily` 不必午夜二次拉取（省一整个 24h 深窗口的上游）。
    代价：备份体积、库文件热度、「研究工具而非归档服务」的人设边界。
    形态建议：env 开关默认关、保留期可配、只存 dedupKey 去重后的最小列、无索引外的
    二级用途、超期 `DELETE` 而非软删。

### H2. 自我免疫第二层

34. **上游契约金丝雀**（S）—— 项目被上游形状漂移咬过至少四次（/activity 排序、gamma
    `closed=true`、/closed-positions 排序截断、/trades NaN）。每日对固定夹具（一个已结算
    市场的价格史、一个已知钱包的首活时间、一页 /trades 的字段集）做形状与数值 diff，漂移
    即 🩺 自检报警，几次调用/天。便宜版：`scripts/dry-run.ts` 挂 GitHub Actions 夜间 cron，

# 全站双语化（中文/英文·手动切换）设计

日期：2026-08-17
状态：用户已委托开发

## 1. 方案选型

**B：客户端语言上下文 + Cookie 持久化（选定）** vs A：/en /zh 分语言路由。

- 用户要的是「手动切换」；B 零路由重构、不动刚建好的 SEO 层
  （canonical/站点地图全不变），A 要把整个 app/ 挪进 [locale]/ 并重做
  SEO——收益（英文页独立收录）留作后续演进，本批不做。
- 首次访问无 cookie 时按 Accept-Language 自动选（en* → en，其余 zh）；
  切换写 `ww_lang` cookie（1 年），服务端 layout 读同一 cookie 定
  `<html lang>` 与 Provider 初始值 → **SSR 与客户端首帧一致，无水合错位**。

## 2. 核心机制：中文原文即字典键

`t("已结算胜率")` → lang=zh 原样返回；lang=en 查字典，**缺译回退中文**
（永不白屏/空串，覆盖率可增量补齐）。带变量的模板：
`t("共 {n} 笔", { n })` —— 中英模板都做占位符插值。

- `lib/i18n/core.ts`（同构零依赖）：`translate(dict, lang, zh, params)`、
  `pickLang(cookieVal, acceptLanguage)`、cookie 常量。
- `lib/i18n/dict/*.ts`：**按页面分片**（common/home/alerts/consensus/
  accumulation/discovery/follow/deep/wallet/market/glossary/misc），
  `index.ts` 合并 —— 分片让并行改造零文件冲突。
- `app/i18n.tsx`（client）：`LangProvider` + `useLang() → { lang, setLang, t }`；
  setLang 同步写 cookie 与 `document.documentElement.lang`。
- 顶栏语言切换按钮（ui.tsx TopNav，「中/EN」）。

## 3. 范围与边界

- **翻译**：全部用户可见字符串 —— JSX 文本、title/aria/placeholder、
  按钮、空态/错误态、确认框、图表标签与悬停读数、词汇表全文。
- **不翻译**：代码注释、console 日志、API 载荷/dedup key、Telegram 与
  X 推送（各有既定语言策略）、emoji 语义标记（既有用户裁决保留）。
- glossary.ts 数据结构**不动**（中文仍是源），显示端过 t()；全部定义
  prose 的译文收在 dict/glossary 分片，**其它页面引用词表定义串时只包
  t() 不重复建键**（glossary 分片是唯一属主）。
- 服务端 SEO 快照条维持「中英双语固定并排」——不依赖 cookie，切换后
  零陈旧，爬虫两种语言都拿到。
- ageFormat 等纯函数模块加可选 lang 参数，由渲染端传入。

## 4. 质量闸

- core 单测：回退/插值/pickLang 矩阵。
- **字典卫生测试**：合并字典无空值、无「译文=原文」的假翻译、
  中英模板占位符集合一致（漏 {n} 直接红）。
- 全量 vitest + tsc；预览逐页切换验证 + cookie 刷新持久。

## 5. 施工组织

基建与共享层（ui.tsx/layout/ageFormat/dict 骨架）先行落地提交；八个
并行子代理按页面分片扫荡（follow 主页/深度分析/词汇表/首页/告警/
共识/累计+发现/钱包+市场），各自只写自有页面文件与自有字典分片；
主会话集成、全量验证、统一提交。

# 赛道 × 策略优势矩阵 + 分段缺陷诊断 — 设计

日期:2026-08-13。用户定向:①跨策略聚合的「赛道 × 策略」edge 热力矩阵,
作为新档位设计的选题池;②定期借助面板累计数据,总结各策略失败率高的
下注特征(赛道、快/慢市场等),定向优化策略。

两者共用同一套「分段统计」底座:把已结算仓按某维度切段,每段算
n/胜率/隐含/edge/落袋 —— 矩阵是(策略 × 细赛道)的二维铺开,诊断是
单策略在(细赛道/时长/赔率带)三个维度上找亏损段。

## 1. 口径(全部沿用既有红线)

- 已结算纸面口径、push 不进胜率分母、edge = 实际胜率 −
  段内均入场价(隐含胜率)。
- 小样本诚实:段内 n < BUCKET_LOW_SAMPLE_N(5)只弱化展示、不参与
  诊断裁决;矩阵格照画但降透明度。
- 细赛道键 = category + subcategory 组合;无二级的仓落「该一级·未细分」
  段(与两级赛道细分同一「子行是细分视图」哲学,但矩阵/诊断需要不重叠
  的分段,故未细分单独成段,不并入一级汇总)。
- 「定期总结」由面板常算常新满足:每次打开都是全量累计数据的即时结论,
  不需要 cron;周报自动化留给后续批次。

## 2. 赛道 × 策略优势矩阵

- **形态**:行 = 启用中的策略 + 顶部「全部(聚合)」行;列 = 数据里实际
  出现过的细赛道,按全体样本数降序(选题池视角:样本多的赛道排前)。
- **格子** = edge(带符号 pt,绿正红负)+ 第二行 n 仓;n<5 半透明;
  该策略在该赛道零仓 → 「—」。title 悬停给全量数字(胜率/隐含/落袋)。
- **聚合行**沿用跨档重复下注口径声明(多档跟进同一信号,样本不独立)。
- **位置**:策略中心页,净值曲线之后、仓位明细之前 —— 它是从「每档的
  net 曲线」到「每仓明细」之间的中观层。仅当有 ≥1 已结算仓时渲染。
- **宽表兜底**:列数 = 细赛道数(当前量级 ~10 内),超宽走 ds-table-wrap
  横向滚动(全站既有 fallback)。

## 3. 分段缺陷诊断(DeepAnalysisPanel 第 ⑦ 块)

- **扫描维度**:细赛道 / 持有时长 5 桶(快慢市场)/ 赔率带 5 桶 ——
  用户点名前两个,赔率带是既有维度顺势纳入。桶定义从 followAnalysis
  导出复用(ODDS_BOUNDS/DURATION_BOUNDS 单一事实源)。
- **缺陷判定**:段内 n ≥ 5 且落袋 < 0。刻意不把 edge<0 设为必要条件:
  亏钱是用户要抓的事实;但 edge ≥ 0 的亏损段标注「edge≥0·或为波动」,
  防止对短期运气过度反应(统计诚实)。
- **排序与上限**:按落袋升序(最亏在前),最多列 5 段。
- **反事实剔除**:每段给「剔除该段后总净盈亏」= totalRealized −
  段落袋。固定 $/仓 + 仓位独立 ⇒ 精确值非估计(与账户推演同一论证)。
  ⚠️ 各段互有重叠(一仓可同时属「足球」与「>7 天」),剔除数字不可
  相加 —— hint 明示。
- **对照**:同时给一条「最强特征」(n≥5 且落袋>0 且 edge>0,取最大
  落袋),定向优化是「砍最亏的、保最强的」两面。
- **无结论时**:「未发现 n≥5 且亏损的特征段」空态,不硬凑。

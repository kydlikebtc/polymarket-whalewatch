## A. 微观结构与归因 —— 从「谁买了」到「市场信了吗」

1. **价格影响持久性评分**（M）——每笔大单落地后价格延续还是回落？回落=噪音，
   持续=市场认为他知道些什么。给钱包算一个与 PnL 正交的「被市场相信程度」
   （微观结构 informed-trading 的经典判据）。原料全在手：价格历史永久缓存 +
   告警台账；验证回填循环已在拉 1h/24h 点位，补几个 horizon 即可。竞品无人做。
2. **无鲸异动反查**（S–M，闸门无关）——价格剧烈移动但窗口内没有对应大单：
   要么簿子薄、要么蚂蚁搬家。日频版直接骑 market_daily 聚合底座做反向 join；
   盘中版需新增价格轮询预算，属另立项。
3. **信号容量标尺**（S，闸门无关）——用开仓时已采的订单簿快照回答「这个信号在
   吃穿簿子前能容纳多少跟随资金」，每档策略挂「可容纳量」。「信号是真的，但只有
   $3k 深」是几乎没人敢发布的诚实指标，恰好长在本项目人设上。
4. **聪明钱离场信号**（M）——现有全部检测都是进场偏置；池内钱包减仓/清仓是另一半
   故事，「白名单正在集体撤出」可能比进场更有信息量。便宜路径：对池内钱包复用
   滚动窗口做**卖侧**累计聚合（零新增上游）；贵路径才是逐钱包持仓轮询。
   与渠道记分卡刚设的「离池桶」呼应。

## B. 钱包作为实体 —— 从「地址」到「角色」

5. **行为指纹聚类 + 相似钱包搜索**（S–M，闸门无关）——odds-band 直方图、品类焦点、
   拆单倾向、下单时点全是现成特征向量；聚出交易原型（狙击手/磨单工/结算清扫者），
   dossier 页加「和他风格最像的钱包」。范围限池内+候选即近零成本（复用评分刷新
   已拉的数据）。
6. **同批出生检测**（S）——N 个新钱包几小时内诞生、随后进入同一市场同一边 =
   协同指纹。链上资金溯源方向已搁置，但行为侧 join 零新增抓取，可直接成为新告警
   家族（配自己的反向对照）。统计告诫：地址年龄覆盖率 43% 且非随机（edge 审计
   已记录），样本声明要随卡出。
7. **鲸鱼编年史 / 名人堂**（S–M，闸门无关）——给反复出现的鲸鱼固定代号与叙事页
   （最佳战役/最惨爆仓/风格画像/生涯时间线），月度鲸鱼榜自动生成 X 线程。
   有角色的数据比有数字的数据留得住人，是内容引擎的「人物化」升级。
8. **反指名单**（M）——把 逆势少数边（+38.9%）从孤例变成一类：用 walk-forward +
   Bonferroni 同款纪律系统性挖「稳定错」的钱包。闸门刚过，这是阈值重推的自然延伸，
   应与重推共用同一套显著性闸。

## C. 把访客拉进实验 —— 从「看我们的记分卡」到「领你自己的」

9. **「你是不是聪明钱」自测**（S，闸门无关）——粘贴地址 → 现成 admissionGate +
   walletProfile 出判决书：过没过准入门槛、池内百分位、可分享战绩卡。全清单最便宜
   的出圈钩子；唯一代价是病毒式成功=上游扇出放大（每新地址 ~42 上游调用），
   必须带 24h 判决缓存 + 既有上游限流一起上线。
10. **自配策略工坊**（M–L）——访客用检测器家族 × 过滤参数拼自己的纸面策略，
    从今天起 forward-only 记分。区别于第二轮 #14（那是告警规则推送）：交付物是
    跑在同一套订单簿执行建模上的**个人诚实战绩账本**。⚠️ 自由式=无界常驻成本
    （每个配置都是一个永续前向实验）；仅「有界参数网格 + 同配置去重」形态可行，
    可骑 walk-forward 挑战者档机制。
11. **市场时光机 / 复盘页**（M，闸门无关）——任一已结算市场重建完整时间线：
    价格曲线 × 鲸鱼成交点 × 共识/分歧告警时刻 × 结算。价格历史永久缓存使其基本是
    纯 UI；副产品是自动生成 X 复盘线程。已知缺口：分歧的连续状态轨迹未落库，
    只有告警点可回放。

## D. 市场自身的风险层 —— 从「谁在买」到「这个市场安全吗」

12. **规则律师**（M，闸门无关）——LLM 解析 gamma 元数据里的结算规则文本，
    打「规则歧义/口径风险分」；进一步检测「规则套利者」——专挑规则含糊市场下注的
    钱包（赌条文不赌事件）。全清单新颖度最高；引入项目第一个 LLM 依赖
    （美元成本，一次性/市场 + 永久缓存可控）。
13. **UMA 结算争议监听**（M）——市场进入 propose/dispute 状态时向相关订阅者推
    「结算争议中」。需一个窄的新上游（UMA oracle 事件），只盯临近结算且池内
    有持仓的市场。战绩口径纠错四件套里「UMA 争议价被钉死」的教训是它的近亲。
14. **洗量/对敲检测**（M，闸门无关）——分歧检测已在丢弃「同钱包双边」假对立，
    推广成滚动窗口内的 wash-trading 市场风险分。与 cover（事件保障）承保输入
    天然协同。⚠️ 只做窗口版；历史版要求归档成交流水，踩存储红线。
15. **Poly-VIX 确信指数**（S，闸门无关）——分歧度 × 量能 × 簿厚 × 校准偏离合成
    每日按品类的「确信/恐慌指数」。纯投影，market_daily 底座现成，
    每天一张可发 X 的图。

## E. 系统的自我免疫 —— 把「诚实」从文化变成机器

16. **策略衰变哨兵**（M）——对每档策略实盘表现做序贯监控（CUSUM/SPRT 风格），
    显著偏离 walk-forward 期望即告警「此档在衰变」。「系统会怀疑自己」是本项目
    最独特的品牌资产，这条把它从年度审计变成 7×24 自动化。
17. **重推日历化**（S）——walk-forward 从一次性大事变成季度例行（/manage 🧪
    触发器已在），每次自动出 diff 报告：「与上次相比哪些结论翻案了」。

## 性能 × 存储成本评估（2026-08-28，裁决参考）

成本三轴的部署事实：限流以**上游请求**计（一次钱包画像 ~42 调用，市场深度卡设计
已确立「预算从属引擎健康度」先例）；成交流水**刻意不归档**（只落事件/结论）；
SQLite 每日快照留 7 → 每持久字节 ≈ ×8 落盘；唯一重 CPU 是按需 walk-forward 子进程。
由此得出判断方法：凡是「现有不可变事实的投影」近零成本；凡是「新增常驻上游轮询」
或「归档原始流水」才真正贵。

## 结构性判断

- **第一梯队五条（3/15/16/17/6）合计一至两周可全部上线**：零新增上游、KB 级存储、
  全是现有数据换问法。其中 16+17 与眼下官方大事（30 天闸门后的阈值重推）直接衔接。
- **第二梯队按叙事需要抽取**：1 是研究护城河（与 8 同批做，共享重推的显著性纪律）；
  11+7 是内容引擎的下一层（复盘线程 + 人物化）；4/5/2/14 是新检测族，各配反向对照。
- **第三梯队三条各引入一种新成本维度**（扇出放大 / LLM 美元 / 新上游），值得做但
  各配预算闸：9 要 24h 判决缓存 + 上游限流实测后再宣传；12 设月度 LLM 花费熔断
  （参照 X 播报 $15/月 fail-closed 先例）；13 只盯池内持仓市场。
- **仅有的两个真正贵的坑**：自由式策略工坊（无界常驻成本，只有「有界网格」形态
  可谈）与任何要求归档成交流水的想法（×8 存储红线，正确形态是只落日聚合结论）。
